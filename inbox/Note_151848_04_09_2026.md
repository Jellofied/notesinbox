What the agent needs from your design
The new user needs structure, not pixels. Some of our instincts flip.

Human user wants	Agent user needs
Visual polish, delight, motion	Predictable structure; animation and inconsistent layouts confuse it
Persuasion — an impulse buy, a nudge	Clear parameters — price, rating, availability — it decides on logic
Ambiguity is fine; we read context	Ambiguity is failure; it needs consistent labels and meanings
A pretty page	A page it can act on: semantic HTML, metadata, machine-readable data
An emotional journey	No sentiment curve — just enough information to complete the task?
